My entry for the [One-Line Office Joke Laugh-Off](https://make.fun/bounty/u-suzy-one-line-office-joke-laugh-off-f574ac73) — one original line about office life:

> My job description said 'fast-paced environment' — corporate for 'three people quit and nobody's replacing them.'

## How it works

`main.ts` (Node.js, no dependencies, builtins only) writes the line above to `entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR`, defaulting to `/output`. The output is byte-exact: the line only, with no trailing newline.

Run it with:

```sh
node main.ts
```
